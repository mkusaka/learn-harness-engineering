# 製品説明 -- ナレッジベース

## これは何ですか？

個人用ナレッジベースを管理するデスクトップアプリケーションです。ユーザーはファイルピッカーからテキストや Markdown の文書を取り込み、文書内容を閲覧できます。システムはそれらを検索可能なチャンクに分割して索引化し、出典付きの根拠ある Q&A を可能にします。

## 主な機能

### 文書管理
- `ImportPanel` のファイルピッカーから `.txt` と `.md` ファイルを取り込めます。
- 文書のメタデータを表示します: タイトル、ファイル名、サイズ、取り込み日時、索引化ステータス。
- スクロール可能なテキストビューアーで文書の全文を表示できます。
- サイドバーで取り込んだすべての文書の一覧を参照できます。
- 文書本体と関連データ（内容ファイル、元のコピー）を削除できます。

### テキスト索引
- 文書を段落の区切りで、およそ 500 文字ごとのチャンクに分割します。
- チャンクをメタデータ（文字数、単語数）付きで保存します。
- 文書ごとおよび全体の索引化ステータスを追跡します。
- 個別の文書、またはライブラリ全体の索引化に対応します。

### 根拠付き Q&A
- 文書ライブラリについて自然言語で質問できます。
- 特定の文書チャンクを指す引用付きで回答を受け取れます。
- 信頼度スコアで回答の確からしさを示します（引用ありは 0.85、引用なしは 0.30）。
- Q&A の履歴全体はセッションをまたいで保持されます。

### 永続化
- 取り込んだ文書は、アプリケーション再起動後もすべて保持されます。
- 文書一覧はアプリケーション起動時に自動で読み込まれます。
- データはユーザーのアプリケーションデータディレクトリにローカル保存されます。

### ステータスバー
- 索引ステータス（idle、indexing、ready、error）をリアルタイムに表示します。
- 文書数と最終アクティビティのタイムスタンプを表示します。

## ユーザーインターフェース

```
+------------------+----------------------------------------+
| Header           |                                Refresh |
+------------------+----------------------------------------+
| Document List    | ImportPanel / Document Detail          |
| (sidebar)        |   - View Content button                |
|                  |   - Show Chunks toggle                 |
| [+ Import]       |   - Index Document button              |
|                  |   - Delete button                      |
+------------------+----------------------------------------+
| Question Input                              [Ask]         |
+-----------------------------------------------------------+
| Status: idle | Documents: N                                |
+-----------------------------------------------------------+
```

## 制約

- 対応する最大ファイルサイズは 10 MB です。
- 対応形式は `.txt`、`.md` です。
- このバージョンの Q&A はモックパターンを使用しており、LLM 連携はありません。
- すべてのデータはローカルにあり、ネットワーク要求は行いません。
