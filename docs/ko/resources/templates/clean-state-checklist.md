# クリーン状態チェックリスト (Clean State Checklist)

セッション終了前にこのチェックリストを実行し、次のセッションがクリーンな状態(clean state)から始められるようにリポジトリを整えてください。エージェント(agent)もセッション終了ルーチンの一部として、これらの項目を確認する必要があります。

- [ ] 標準の開始パスが引き続き動作します。
- [ ] 標準の検証(verification)パスが引き続き実行されます。
- [ ] 現在の進行状況が進行ログ(progress log)に記録されています。
- [ ] 機能の状態が、実際に通過(passing)したものと未検証のものを反映しています。
- [ ] 未完了のステップが文書化されないまま残っていません。
- [ ] 次のセッションが手動修正なしで続行できます。
