# セッション引き継ぎ (Session Handoff)

このセッションが終了したあと、次のセッションがすばやく引き継げるようにするための簡潔な handoff ノートです。エージェント(agent)がセッション終了時にこのファイルを埋めることも、人が直接埋めることもできます。セッションが長い場合や、プロジェクトに複数の進行中領域がある場合に特に重要です。
