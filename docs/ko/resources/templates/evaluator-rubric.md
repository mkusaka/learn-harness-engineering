# 評価者ルーブリック (Evaluator Rubric)

実装後、最終承認の前にこのルーブリック(rubric)を使用してください。エージェント(agent)は自己評価が弱い傾向があるため、このスコアカード(scorecard)を繰り返し調整(calibration)して、人間の判断と一致するようにする必要があります。

| 項目 (Category) | 質問 (Question) | 点数 (0-2) | 備考 (Notes) |
| --- | --- | --- | --- |
| 正確性 (Correctness) | 実装された動作は要求された機能と一致しているか? |  |  |
| 検証 (Verification) | 必要な確認は、証拠(evidence)とともに実際に実行されたか? |  |  |
| 範囲の規律 (Scope discipline) | セッションは選択した機能範囲内にとどまっていたか? |  |  |
| 信頼性 (Reliability) | 結果は再起動または再実行後も修正なしで維持されるか? |  |  |
| 保守性 (Maintainability) | コードと文書は次のセッションで十分に理解可能か? |  |  |
| 引き継ぎ準備性 (Handoff readiness) | 新しいセッションは、リポジトリの成果物(repo artifacts)だけで作業を継続できるか? |  |  |

## 判定 (Verdict)

- Accept
- Revise
- Block

- Required fixes:
