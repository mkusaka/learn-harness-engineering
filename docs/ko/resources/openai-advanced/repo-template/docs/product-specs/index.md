# 製品仕様(Product Specs) インデックス

このフォルダは、ユーザー向けの動作仕様に使用してください。

製品仕様(product spec)は、機能のユーザーに見える動作と受け入れ基準(acceptance criteria)を定義します。エージェント(agent)が仕様を参照することで、実装が製品意図から外れるのを防ぎます。

## 有効な仕様

- `new-user-onboarding.md`

## ルール

- 仕様は、ユーザーに見える動作と受け入れ基準を説明しなければならない。
- 実装が仕様から外れた場合は、同じセッションでどちらか一方を更新する。
- 新しいエージェントが製品範囲をすばやく把握できるよう、このインデックスを最新の状態に保つ。
