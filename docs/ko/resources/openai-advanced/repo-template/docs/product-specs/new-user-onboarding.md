# 新規ユーザーオンボーディング(New User Onboarding)

## 目的

新規ユーザーが初回利用時にどのような体験をするべきかを説明します。

オンボーディング(onboarding)は、新しいユーザーがサービスに初めて触れるときに通る導入フローです。この仕様は、エージェント(agent)がオンボーディングフローを実装または修正するときに参照する唯一の正確な情報源(single source of truth)です。
