# 技術負債トラッカー(Tech Debt Tracker)

実際に存在し、認識されていて、意図的に先送りされている技術負債(tech debt)にこのファイルを使用してください。

技術負債とは、より良い方法があると分かっていながらも、時間・リスク・優先度などの理由で意図的に選んだ代替案です。これを明示的に追跡することで、エージェント(agent)とチームメンバーは、どの領域に改善が必要か、その理由は何かをひと目で把握できます。

| 日付 | 領域 | 負債 | 先送りした理由 | リスク | 次のトリガー |
|------|------|------|----------|------|------------|
| YYYY-MM-DD | `[area]` | `[debt]` | `[reason]` | `[risk]` | `[when to revisit]` |
