# QUALITY_SCORE.md

この文書は、リポジトリが時間の経過とともに強くなっているのか、それとも弱くなっているのかを追跡します。

品質スコア(`quality score`) は、単なるテストカバレッジを超えて、エージェントにとっての読みやすさ・境界の強制・安定性の観点から、各ドメインと各レイヤーの健全性を定期的に評価するための指標です。これにより、負債が積み上がる前に早期に検出できます。

## 等級の目安

- `A`: 検証済み、読みやすい、安定している、境界が強制されている
- `B`: 小さな抜けはあるが動作する
- `C`: 部分的に動作する、目立つ混乱や不安定さがある
- `D`: 壊れている、安全ではない、または構造的に不明確である

## 製品ドメイン

| ドメイン | 等級 | 検証 | エージェントの可読性 | テストの安定性 | 主な抜け | 最終更新 |

| `[domain-a]` | - | - | - | - | - | - |
