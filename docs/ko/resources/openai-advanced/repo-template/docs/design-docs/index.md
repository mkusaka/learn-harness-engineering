# 設計ドキュメント(Design Doc) インデックス

このインデックスを、設計の履歴をたどるための発見可能な地図として使ってください。

設計ドキュメント(design doc) は、単なる実装の説明ではなく、「なぜその決定を下したのか」という根拠を記録する文書です。状態(承認済み・提案中・破棄済み)を明示的に管理することで、エージェント(agent) が有効な決定と古い決定を区別できるようになります。

## 保守ルール

- すべての設計ドキュメントには、所有者または更新トリガーが必要です。
- 古くなった文書は破棄扱いにするか削除し、放置しないでください。
- 有効な実行計画(execution plan)は、それが依存する設計ドキュメントにリンクしてください。
