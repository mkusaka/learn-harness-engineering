# 核心となる信念(Core Beliefs)

この文書は、プロジェクト全体でエージェント(agent)と人間が共有する、エージェント優先(agent-first)の運用原則をまとめたものです。個々の判断よりも上位にあるこれらの信念は、曖昧な状況での判断基準になります。

- リポジトリは、エージェントのための system-of-record である。
- `AGENTS.md` はルーターであって、百科事典ではない。
- 検証可能な証拠は、自信よりも重要である。
- 中途半端な作業をたくさん抱えるより、ひとつの制約された作業に集中するほうがよい。
- 人から繰り返し寄せられるフィードバックは、再利用可能な harness ルールにすべきである。
- 整理と単純化はリリースの一部であり、後処理ではない。
- エージェントがリポジトリ内で事実を見つけられないなら、その事実は運用上利用不可能なものとして扱う。
