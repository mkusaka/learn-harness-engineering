# データベーススキーマ(Database Schema)

このフォルダは、エージェント(agent)がコードをリバースエンジニアリング(reverse-engineering)しなくても検査できるように、生成(generated)された成果物(artifact)や派生物を保管するために使用してください。

生成された成果物をリポジトリに明示的に保管しておくと、エージェントが元のコードを分析しなくても現在のスキーマや派生データをすぐに参照できるため、コンテキスト(context)の消費を抑え、分析速度を高められます。

## 出力元

- 生成場所: `[コマンドまたはソースパス]`
- 最終更新: `YYYY-MM-DD`

## 備考

- 生成されたセクションを直接手動で編集しないでください。
- 基本スキーマが変更された場合は、このファイルを再生成してください。
