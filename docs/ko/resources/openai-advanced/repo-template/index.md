# 高度なリポジトリテンプレート(Advanced Repo Template)

最小限のハーネス(harness)だけでは不十分で、OpenAI スタイルの agent-first なドキュメント体系が必要なときは、このスターターを実際のリポジトリにコピーしてください。

リポジトリテンプレート(repo template)とは、エージェントと人間の両方がプロジェクトのコンテキストをすばやく把握し、段階的により深い情報へたどれるように構成されたスターターファイル群です。

## コピー手順

1. `AGENTS.md` と `ARCHITECTURE.md` をリポジトリのルートにコピーします。
2. `docs/` ツリー全体をコピーします。
3. `docs/PRODUCT_SENSE.md`、`docs/QUALITY_SCORE.md`、`docs/RELIABILITY.md` を最初に埋めます。
4. `docs/exec-plans/active/` の下に最初のアクティブプラン(active plan)を追加します。
5. エントリーポイントのファイルは短く保ち、詳細は関連するドキュメントへ振り分けます。

## このテンプレートが最適化するもの

- 継続的なリポジトリローカルコンテキスト
- 1つの巨大な指示ファイルではなく、段階的公開(progressive disclosure)
- 明示的な計画ライフサイクル
- 時間の経過に伴う品質追跡
- エージェントと人間の両方にとって読みやすい境界

ここにあるすべてのファイルはスターターとして扱ってください。実際に使う前に、プレースホルダー、例、サンプルコマンドを実際のプロジェクト内容に置き換えてください。
