# 仕様が不足しているタスクの例

AI の質問応答機能を備えたデスクトップのナレッジベースアプリを作ってください。

制約条件:

- 明示されたものはありません
- 起動コマンドなし
- フォルダ構成の案内なし
- データモデルの定義なし
- 明示的な完了基準（Definition of Done）なし

この種のプロンプトで起こりがちな結果:

- エージェント（agent）が場当たり的に構造を作ってしまう
- アプリはコンパイルできても、安定して起動しないことがある
- 利用可能な収集・参照経路がないまま、先に UI が表示されることがある
- エージェントが見かけ上の成功で止まってしまうことが多い
