# プロジェクトへようこそ

ここは Learn Harness Engineering の実践（hands-on）セクションです。講義を読むだけでは十分ではありません。実際に環境を構築し、さまざまなルールの下で Codex、Claude Code、または他の AI エージェント（agent）がどのように動作するかを観察してください。

## プロジェクト概要

この講義は、信頼できるエージェント作業環境をゼロから構築する方法を学ぶ、段階的に難易度が上がる 6 つの実践プロジェクトで構成されています。

1. **プロンプト単独 vs. ルール優先（Rules-First）**: プロンプトだけを使う場合と、基本的なハーネス（harness）を備えた場合でのエージェント性能を比較します。
2. **エージェントが読みやすい作業空間**: リポジトリを AI に適した形に構造化する方法と、ハンドオフ（handoff）メカニズムを確立する方法を学びます。
3. **マルチセッション継続性（Multi-Session Continuity）**: エージェントがセッション間で作業を円滑に再開できるように、状態（state）ファイルと初期化（initialization）スクリプトを設計します。
4. **ランタイムフィードバックとスコープ制御**: エージェントが自分のコードをテストし、実行中のエラーを修正できるツールを導入します。
5. **自己検証と役割分離**: 幻覚（hallucination）や性急な完了宣言を防ぐための独立したレビュー機構を構築します。
6. **完全なハーネス（キャップストーン）**: 観測可能（observable）で完成されたエンドツーエンドのエージェント作業環境を組み立てます。

## 進め方

各プロジェクトフォルダには、通常次のものが含まれます。

- `starter/`: 開始用の作業領域です。
- `solution/`: 参照実装です（行き詰まったら参考にしてください）。
- 背景知識と具体的な目標を説明する作業手順です。

`starter/` ディレクトリ内で、好みの AI コーディングエージェント（例: Claude Code, Cursor, Trae）を使って作業を完了してください。
