# QUALITY_SCORE.md

このドキュメントは、リポジトリが時間の経過とともに強くなっているか、弱くなっているかを追跡します。

## 評価基準

- `A`: 検証済み、読みやすい、安定している、境界が守られている
- `B`: 概ね動作しているが、わずかな抜けがある
- `C`: 部分的には動作するが、混乱や不安定さが目立つ
- `D`: 壊れている、安全でない、または構造が不明確
