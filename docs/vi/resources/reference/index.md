- [`coding-agent-startup-flow.md`](./coding-agent-startup-flow.md): 以降の coding 実行における固定のセッション開始フロー
- [`prompt-calibration.md`](./prompt-calibration.md): 元の指示の鋭さを保ち、肥大化させたり壊れやすくしたりしない方法
