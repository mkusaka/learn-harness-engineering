## 必須のランタイムシグナル

- 起動時および重要なフロー向けの構造化ログ
- 主要サービスの health チェック
- 利用可能な場合は、遅い経路のためのトレーシングまたはタイミング情報
- 復旧可能な障害に対する、ユーザーに見えるエラー状態

## 信頼性のルール

- その後にシステムをきれいに再起動できないなら、どの機能も完了したとは見なしません。
- ランタイムの障害は、リポジトリ内のローカルなシグナルだけで診断できる必要があります。
- 繰り返し発生する失敗モードが現れたら、それ用のベンチマークまたは抑制策を追加してください。
- 片付けは信頼性の一部であり、別個の作業ではありません。
