# QUALITY_SCORE.md

この文書は、リポジトリが時間とともに強くなっているのか、それとも弱くなっているのかを追跡します。

## スコア基準

- `A`: 検証済み、読みやすい、安定している、境界が守られている
- `B`: 小さな抜けはあるが動作する
- `C`: 部分的に動作するが、混乱や不安定さが目立つ
- `D`: 壊れている、安全でない、または構造が不明瞭
