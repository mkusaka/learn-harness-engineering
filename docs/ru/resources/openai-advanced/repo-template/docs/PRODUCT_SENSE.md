# PRODUCT_SENSE.md

このファイルは、エージェントがコードだけでは確実に導き出せない、
長期的に効くプロダクト上の判断を記録します。

## プロダクトの核

- 主なユーザー: `[置き換え]`
- Job to be done: `[置き換え]`
- 解消すべき最大のストレス: `[置き換え]`
- 受け入れの品質基準: `[置き換え]`

## プロダクトのルール

- ユーザーから見える信頼性は、機能数より優先してください。
- あいまいな挙動は、推測してよい許可ではなく、仕様の抜け漏れとして扱ってください。
- 実装がユーザーに見えるもの、またはユーザーが信頼しているものを変える場合は、対応する仕様を更新してください。
- 個別のフローには各プロダクト仕様を使い、このファイルは横断的な
  プロダクト上の優先事項のために使ってください。

## 禁止パターン

- ユーザーに見えない破壊的な動作
- ユーザーへのフィードバックがない静かな失敗
- 目に見える状態について、真実の情報源が不明確なこと
- 一言で説明できない機能
