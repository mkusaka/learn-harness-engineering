# Advanced Repo Template

OpenAI 風の agent-first なドキュメント基盤が必要で、単なる最小限の harness では足りないときに、
このスターターを実際のリポジトリにコピーしてください。

## コピー手順

1. `AGENTS.md` と `ARCHITECTURE.md` をリポジトリのルートにコピーします。
2. `docs/` ディレクトリ全体をコピーします。
3. まず `docs/PRODUCT_SENSE.md`、`docs/QUALITY_SCORE.md`、`docs/RELIABILITY.md` を埋めます。
4. 最初のアクティブなプランを `docs/exec-plans/active/` に追加します。
5. 入力ファイルは短く保ち、詳細は関連ドキュメントへ逃がします。

## このテンプレートの用途

- 長期的に使えるリポジトリ内コンテキスト
- 1つの巨大な指示ファイルではなく、段階的に開示する構成
- 明示的なプランのライフサイクル
- 時間経過に伴う品質追跡
- エージェントと人間の双方にとって読みやすい境界

ここにある各ファイルはスターターだと考えてください。プレースホルダ、例、デモ用コマンドは、
それを頼りにする前に、あなたのプロジェクト固有の内容に置き換えてください。
