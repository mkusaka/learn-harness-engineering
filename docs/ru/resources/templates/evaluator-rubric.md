# evaluator 用ルーブリック

このルーブリックは、実装後から最終承認前までの間に使用してください。

| カテゴリ | 質問 | 点数 (0-2) | メモ |
| --- | --- | --- | --- |
| Correctness | 実装された挙動は、依頼された機能に一致していますか？ |  |  |
| Verification | 必要な検証は、証跡付きで実際に実行されましたか？ |  |  |
| Scope discipline | セッションは、選択した機能スコープの範囲内に収まっていましたか？ |  |  |
| Reliability | 結果は、修正なしで再起動や再実行に耐えますか？ |  |  |
| Maintainability | 次のセッションが理解できる程度に、コードとドキュメントは明確ですか？ |  |  |
| Handoff readiness | 新しいセッションは、リポジトリ内の成果物だけで作業を続けられますか？ |  |  |

## 判定

- Accept
- Revise
- Block

## 必要な対応

- 不足している証跡:
- 必要な修正:
- 次回レビューのトリガー:
