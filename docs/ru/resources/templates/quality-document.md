# 品質ドキュメント

各プロダクトドメインとアーキテクチャ層ごとの品質スナップショットです。エージェントも人間も、このドキュメントを使って、コードベースの強みと、改善が必要な箇所をすばやく把握できます。

**更新頻度:** 重要なセッションごと、または新しい作業フェーズを始める前。

**評価基準:**

- **A**: すべての検証が通る、クリーンなアーキテクチャ、エージェントにとって読みやすい、安定したテスト
- **B**: 検証は通る、概ねきれい、読みやすさまたはテストカバレッジに軽微な不足がある
- **C**: 部分的に動作する、既知の不足がある、コードの一部がエージェントにとって理解しづらい
- **D**: 動作しない、または深刻な構造上の問題がある
