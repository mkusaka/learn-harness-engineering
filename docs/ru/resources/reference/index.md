# 英語のリファレンス

このメモでは、テンプレートをばらばらなファイルの寄せ集めではなく、実際に使える harness として扱う方法を説明します。

## リファレンスメモ

- [`method-map.md`](./method-map.md): 長時間のタスクでよくある失敗パターンを、それを最初に解決する成果物やポリシーに対応付けます
- [`initializer-agent-playbook.md`](./initializer-agent-playbook.md): 機能開発に入る前に、initializer が残しておくべきもの
- [`coding-agent-startup-flow.md`](./coding-agent-startup-flow.md): 以後のコード実行に向けた、セッション開始時の固定フロー
- [`prompt-calibration.md`](./prompt-calibration.md): ルート指示を肥大化させたり壊れやすくしたりせずに、鋭く保つ方法

## 推奨読む順

1. `method-map.md`
2. `initializer-agent-playbook.md`
3. `coding-agent-startup-flow.md`
4. `prompt-calibration.md`
