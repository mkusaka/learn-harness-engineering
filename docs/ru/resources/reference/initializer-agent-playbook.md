# 初期化エージェントのプレイブック

このプレイブックは、リポジトリで最初の本格的なセッションを行うときに使います。機能の段階的な実装を始める前に参照してください。

## 目的

後続のセッションが、開始コマンド、現在の状態、タスクの境界を毎回やり直しで引き直さなくても、振る舞いの実装に集中できる安定した運用基盤を作ることです。

## 必須成果物

初期化担当は、少なくとも次の成果物を残してください。

- ルートの指示ファイル。たとえば `AGENTS.md` や `CLAUDE.md`
- 機能の機械可読な一覧。たとえば `feature_list.json`
- 長期的に残る進捗アーティファクト。たとえば `claude-progress.md`
- 標準の起動ヘルパー。たとえば `init.sh`
- ベースの骨組みを固定する、最初の安全なコミット

## チェックリスト

1. 標準の起動手順を定義します。
2. 標準の検証手順を定義します。
3. 進捗ログを作成し、初期状態を記録します。
4. 仕事を、ステータス付きの明示的な機能に分解します。
5. 最初のクリーンな baseline コミットを作成します。

## 成功条件

チャットの過去コンテキストがない新しいセッションでも、次の問いに答えられる必要があります。

- このリポジトリは何をするのか
- どうやって起動するのか
- どうやって検証するのか
- 何が未完了なのか
- 次に取るべき最善の手順は何か
