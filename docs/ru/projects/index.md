# プロジェクトへようこそ

これは Learn Harness Engineering コースの実践編です。講義を読むだけでは不十分で、環境を自分で組み上げ、Codex、Claude Code、その他の AI エージェントがさまざまなルールの下でどう振る舞うかを観察する必要があります。

## プロジェクト概要

このコースには、信頼性の高いエージェント向け作業環境をゼロから構築するための、段階的な 6 つの実践プロジェクトがあります。

1. **プロンプトのみ vs. ルール優先**: プロンプトだけで動かす場合と、基本的な harness を使う場合で、エージェントの挙動を比較します。
2. **エージェントが読みやすいワークスペース**: リポジトリを AI にとって扱いやすい形に整理し、作業の引き継ぎ仕組みを整えます。
3. **セッション間の継続性**: 状態ファイルと初期化スクリプトを設計し、エージェントがセッションをまたいで作業を途切れなく続けられるようにします。
4. **実行時フィードバックとスコープ制御**: エージェントが自分のコードをテストし、実行中にエラーを修正できるツールを導入します。
5. **自己検証と役割分担**: 幻覚や早すぎる完了宣言を防ぐために、独立したレビュー機構を構築します。
6. **完全な harness (capstone)**: 最終的な、可観測で end-to-end なエージェント作業環境を組み上げます。

## 進め方

各プロジェクトのフォルダには、通常次のものがあります。
- `starter/`: あなたの開始用ワークスペース。
- `solution/`: 参考実装です（行き詰まったときに確認してください）。
- コンテキストと具体的な目標を説明する課題手順。

`starter/` ディレクトリ内の課題には、好みの AI Coding Agent（たとえば Claude Code、Cursor、Trae）を使って取り組んでください。
