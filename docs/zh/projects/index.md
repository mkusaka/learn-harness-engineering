# プロジェクト実践へようこそ

ここは Learn Harness Engineering の実践パートです。講義を読むだけでは不十分で、実際に環境を構築し、Codex や Claude Code などの Agent が異なるルールのもとでどう振る舞うかを自分の目で確かめる必要があります。

## プロジェクト概要

このコースには、完成度を段階的に高めていく 6 つの実践プロジェクトが含まれています。ゼロから、ひと通りの Agent ワーク環境を構築していきます。

1. **Prompt 駆動 vs ルール駆動**：純粋に Prompt だけで動く Agent と、基本的な Harness を備えた Agent の振る舞いの違いを比較します。
2. **プロジェクトを読みやすくし、前回の作業を受け継ぐ**：コードベースの構造を AI にとって扱いやすい形へ再設計し、作業の引き継ぎ機構を作ります。
3. **会話をまたいだ作業の継続性**：状態ファイルと初期化スクリプトを設計し、複数回の対話中断後でも Agent がシームレスに作業を再開できるようにします。
4. **実行フィードバックと挙動の修正**：実行時フィードバックの仕組みを導入し、Agent 自身がコードの実行可否を確認してエラーを修正できるようにします。
5. **作業レビューと自己検証**：独立したレビューと検証の工程を設け、Agent が「幻覚」を起こしたり、先走って完了を宣言したりするのを防ぎます。
6. **統合された Agent ワーク環境**：可観測性を備えた、完成形の Agent ワーク環境一式を構築します（総合演習）。

## 進め方

各プロジェクトのフォルダには通常、次のものが含まれています。
- `starter/`：作業を始めるためのワークスペースです。
- `solution/`：参考用の最終実装です（行き詰まったときに参照できます）。
- 今回の課題の背景や目的を説明する関連ガイド文書です。

お使いの AI Coding Agent（Claude Code、Cursor、Trae など）を使って、各プロジェクトの `starter/` ディレクトリで課題を進めてください。
