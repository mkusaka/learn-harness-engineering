# 高度なリポジトリテンプレート

リポジトリを、単なる最小限の harness ではなく、OpenAI の資料にあるような agent-first のドキュメント構成に近づけたいなら、このスターターテンプレートをコピーしてください。

## 推奨するコピー順

1. まず `AGENTS.md` と `ARCHITECTURE.md` をリポジトリのルートに置きます。
2. 次に `docs/` ディレクトリ全体をコピーします。
3. `docs/PRODUCT_SENSE.md`、`docs/QUALITY_SCORE.md`、
   `docs/RELIABILITY.md` を優先して埋めます。
4. `docs/exec-plans/active/` 配下に最初の active plan を作成します。
5. エントリーファイルは常に短く保ち、詳細なルールはリンク先の文書に分離します。

## このテンプレートが主に改善するもの

- 永続的な repo-local のコンテキスト
- 1つの超長い instruction ファイルではなく、段階的な開示
- 明確な計画ライフサイクル
- 時間とともに進化する品質トラッキング
- agent にも人にも読みやすい境界

ここにある各ファイルは、あくまで出発点です。実運用に入る前に、プレースホルダーの文言、サンプルコマンド、例示ルールを自分のプロジェクトの実態に置き換えてください。
