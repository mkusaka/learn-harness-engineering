# RELIABILITY.md

このファイルは、システムが健全で、診断可能で、再起動可能であることをどう証明するかを定義します。

## 標準パス

- Bootstrap：`[command]`
- Verification：`[command]`
- 启动应用或服务：`[command]`
- デバッグまたは実行状態の確認：`[command]`

## 必須の実行シグナル

- 起動時および重要なフローの構造化ログ
- 重要なサービスの health check
- 条件が許す場合は、遅いパスに対する trace または timing データ
- 回復可能な失敗に対するユーザーに見えるエラー状態

## 重要な旅程

- `[journey 1]`
- `[journey 2]`
- `[journey 3]`

各重要な旅程には、再現可能な検証パスと明確な失敗シグナルが必要です。

## 信頼性ルール

- システムをきれいに再起動できない限り、その機能は完了したとは言えません。
- 実行時の失敗は、repo-local のシグナルから特定できなければなりません。
- ある種の失敗パターンが繰り返し発生するなら、benchmark または guardrail を追加してください。
- cleanup は信頼性の一部であり、別物ではありません。
