# Prompt 校准

ルート指示ファイルは、すべての動作を固定するのではなく、作業の枠組みを定義するべきです。

## ルートファイルに残すべき内容

- リポジトリの用途と範囲
- 起動手順
- 検証手順
- 破ってはいけない制約
- 必須の状態成果物
- セッション終了時のルール

## ルートファイルから移すべき内容

- 長すぎる過去の例外ケース
- あるサブシステムにしか関係しない詳細な実装説明
- コードの近くに置いたほうがよい局所的なアーキテクチャノート
- 単一モジュールにしか当てはまらない例

## 作業原則

ルートファイルの役割は、新しいセッションがすばやく方向感をつかめるようにすることです。これが「過去に失敗するたび、そこへ一文ずつ足していく」ような積み重ね状態になり始めたら、詳細はより小さく明確な文書に分け、ルートファイルからそこへ誘導するようにしてください。
