# 初期エージェント運用手引き

この手引きは、リポジトリで最初に行う重要な会話、つまり本格的な増分開発に入る前の初期化段階を対象にしています。

## 目的

まず安定した作業基盤を整え、後続の会話で起動コマンド、現在の状態、タスクの境界を毎回推し直さなくて済むようにします。

## 必須成果物

初期化段階では、少なくとも次の成果物を残すべきです。

- ルートの指示ファイル。例: `AGENTS.md` または `CLAUDE.md`
- 機械可読な機能一覧。例: `feature_list.json`
- 永続的な進捗成果物。例: `claude-progress.md`
- 標準的な起動補助スクリプト。例: `init.sh`
- 基本的なスキャフォールド状態を記録した最初の安全なコミット

## チェックリスト

1. 標準的な起動手順を定義する
2. 標準的な検証手順を定義する
3. 進捗ログを作成し、初期状態を書き込む
4. 作業を機能単位に分割し、状態フィールドを用意する
5. 最初のクリーンな baseline commit を作成する

## 成功基準

前提となるチャット文脈が一切ない新しい会話でも、次の問いに答えられる状態にします。

- このリポジトリは何をするものか
- どう起動するか
- どう検証するか
- 何がまだ未完了か
- 次に取るべき最善の行動は何か
